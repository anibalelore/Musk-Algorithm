# Guía de operaciones, logística, asistencia y fabricación

## Antes de eliminar procesos

Mapear el flujo con su recorrido físico, digital y de responsabilidad. Distinguir demanda, validación, asignación, ejecución, control de calidad, cierre y contingencia.

Para cada paso: entrada, salida, actor, sistema, tiempo efectivo, cola, retrabajo, tasa de fallo y por qué existe. Un control de calidad puede parecer tiempo improductivo, pero prevenir un fallo caro y peligroso: comprobar su valor total.

## Buscar desperdicio

- Doble digitación; filas de aprobaciones redundantes; espera entre sistemas.
- Viajes, tareas o recogidas innecesarias.
- Revisión duplicada sin valor incremental.
- Transferencia de información que ya existe en fuente de verdad.
- Variantes que pueden normalizarse sin perder trazabilidad.

## Rediseñar

1. Quitar pasos prescindibles con validación de seguridad.
2. Unificar datos y responsables; eventos claros por cambio de estado.
3. Reducir handoffs y esperas; ejecutar en paralelo únicamente cuando sea seguro.
4. Medir ciclo total, no solo rapidez de cada operario.
5. Automatizar el cuello de botella real, nunca todo el flujo de una vez.

## Controles de seguridad

Mantener protocolos de emergencia, autorizaciones, verificación de identidad, manejo seguro de vehículos/carga, inspecciones requeridas, cadena de custodia y evidencia de entrega. No reemplazar confirmación humana ante riesgos físicos por salida probabilística de un modelo de lenguaje.

## Indicadores

Lead time = cierre - solicitud. Cycle time = tiempo de ejecución de una unidad/servicio según definición explícita. Medir también tiempo de espera, tasa de resolución, primer intento exitoso, incidentes, retrabajo y costo por operación.

Para redes de proveedores distinguir «opción encontrada» de «proveedor acepta» y de «servicio completado». El sistema debe mostrar cobertura real, no deducirla de un directorio.
