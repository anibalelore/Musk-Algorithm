# Evaluación de suficiencia

Usar la matriz de `references/adaptive-discovery.md` y registrar puntuación, evidencia, relevancia y brecha. Es bloqueante una contradicción que invalide el flujo o una dimensión esencial por debajo de 3 necesaria para proponer DELETE con seguridad.

Decisiones: `ADVANCE_TO_DELETE`, `ADVANCE_WITH_UNCERTAINTIES`, `CONTINUE_DISCOVERY`, `INVESTIGATE_BLOCKER`. No confundir «hay más por aprender» con «no se puede actuar». Mantener asuntos no esenciales como investigaciones posteriores.

Si el host permite Python, `scripts/session_engine.py` ofrece una política comprobable. El agente explica la recomendación y conserva el juicio humano.
